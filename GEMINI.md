# WORKSPACE RULES FOR CIMOFOOD PROJECT
1. Selalu baca dan patuhi `PRD.md` sebagai satu-satunya sumber kebenaran (Single Source of Truth) untuk alur bisnis, skema database, dan desain UI.
2. Seluruh teks antarmuka pengguna (UI) wajib menggunakan Bahasa Indonesia yang ramah, jelas, dan profesional.
3. Halaman `/admin` wajib didesain dengan pendekatan Laptop & Tablet First (tombol minimal h-12, layout lega, mudah dioperasikan dengan sentuhan jari di tablet maupun kursor di laptop).
4. Halaman publik (`/`, `/checkout`, `/track`) wajib didesain Mobile-First dengan nuansa warna hangat khas kuliner camilan renyah (kombinasi warna Amber/Oranye Hangat, Merah Cabai, dan Putih Bersih).
5. Setiap selesai mengerjakan satu fase/fitur, perbarui file `PROGRESS.md` di root folder dengan daftar file yang dibuat/diubah dan status fitur saat ini.
